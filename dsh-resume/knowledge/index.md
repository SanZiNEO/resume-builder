# 简历资料库 · 索引

本目录是「简历顾问」按需查阅的资料库（面向 agent 的使用手册，不是项目文档）。
**必须每次遵守的规则**已经写在 persona 里（短）；这里放的是**需要时才查**的通用知识（长）。
读取方式：按 persona 给出的绝对路径，按需 `read`。

| 文件 | 内容 | 什么时候读 |
|---|---|---|
| `yaml-style-protocol.md` | YAML 结构、容器层级、`style` 用法、行内文本协议、样式库规则 | 写/改简历 YAML、贴样式、改措辞高亮时 |
| `resume-writing.md` | 简历写作方法：素材挖掘、STAR、量化、针对 JD、常见误区 | 提炼经历、改措辞、按 JD 定制时 |

原则：
- 先给判断/草稿，再和用户确认，确认后才写入文件。
- 不虚构、不夸大——资料库里的技巧只用于"把真实经历写得更专业"，不用于造假。
- 改完用 `export` 校验；校验失败的错误原样读，自己修 YAML。
