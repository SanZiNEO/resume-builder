# 简历写作方法（合规版）

> 来源：两份写作素材（B站 BV1Cs2JYnEWi、BV1f4qpBXEck）的**合规提炼**。
> 已剔除与"不虚构 / 不夸大"红线冲突的内容（如"骗过 HR"式话术）。
>
> **允许**：专业的措辞、真实经历的结构化表达、量化、排序、按 JD 取舍、突出与岗位相关的点。
> **禁止**：编造经历 / 数字 / 奖项 / 技能；把没做过的事写成做过；用含糊话术掩盖"其实没做"。
> 一句话：可以把**真做过的事**写得更专业，不能把**没做过的事**写成做过。

## 一、先挖素材：几乎人人有东西可写

不要轻易接受"我没什么可写"。从这些方向自然挖掘：
课程 / 小组作业 / 社会调查 / 实习 / 兼职 / 社团与干部 / 比赛 / 志愿 / 项目 / 技能 / 兴趣 / 自媒体。

"深挖"的正确含义是**把真实经历还原成它真正的分量**，而不是无中生有：
- 做过调研作业 → 真实存在的"调研 / 分析 / 策划 / 团队协作"经历。
- 做过兼职服务 → 真实的"抗压 / 沟通 / 熟悉流程"经历。
- 玩过游戏、剪过视频、在闲鱼卖过东西 → 若与目标岗位相关，就是真实的运营 / 内容 / 交易经历。

⚠️ 边界：只写**确实发生过**的角色、动作、成果。没当过组长就不要写"组长"。

## 二、STAR：把经历写成闭环

推荐用 STAR 组织实习/项目经历（HR 最熟悉这种结构）：
- **S** 情境：在哪、什么背景（常已写在标题行）。
- **T** 任务：要达成什么。
- **A** 行动：**你**具体做了什么。
- **R** 结果：做出了什么成果（尽量带数据）。

要点：突出"你"的动作，而不是团队笼统做了什么。

## 三、量化：给数字找参照物

- 尽量用具体数据描述结果：做了多少场、参与多少人、拉新/促活/留存多少、相比之前提升多少。
- "厉害与否是比出来的"：给数字加**参照物**——排名在多少人中第几、奖学金是全校前百分之多少、绩点满分是 4 还是 5、涨幅百分比。
- 用数据佐证能力断言：说"领导力强"就要能说出带了多少人、做了什么事、成果数据如何。
- **没有准确数据时，不要编。** 可以写定性结果，或请用户提供真实数字。

## 四、突出：只划 1–2 个，且和 JD 匹配

- 用加粗 / 高亮突出关键词**是对的**，但：
  1. 方式**最多两种**，别搞得花花绿绿；
  2. 每段**1–2 个**关键词即可，不要通篇划重点；
  3. 优先划**和 JD 匹配**的关键词；
  4. 划出来的词要**经得起追问**——面试官会抠细节，划"独立策划""领导团队"这类大词前先确认用户真扛得起。

## 五、取舍：只写和岗位有关的

- 只写**和当前求职岗位相关**的爱好与成就。无关的爱好/成就不仅无用，还可能让人怀疑你能否专注工作。
- 成就不要罗列一堆，会淹没重点；挑最相关、最有分量的。
- HR 看简历很快，重点要**一眼可见**。

## 六、按 JD 定制（核心流程）

1. 拿到 JD，提取关键词 / 能力要求。
2. 对照用户简历，指出匹配点与缺口。
3. 调整措辞、把匹配的关键词前置/突出、按重要性重排条目。
4. 复制一份简历改名作为"目标版"，在副本里改，**不动标准通用版**。

> 相关性：投不同的岗位准备不同版本，不要一张简历走天下。

## 七、其他可行的合规做法

- 学校 / 专业：若知名度不高，可在括号里补充客观标签（985/211/双一流、学科评级、专业排名、QS 排名）。
- 公司 / 部门：可简述其行业地位与部门重要性，方便对方判断。
- 加分项：能展示技术力/作品的链接（个人网站、作品集、飞书云文档）可放进简历；注意版本管理与隐私。
- 投递方式：内推码能提高被看到的机会，来源层级越高越好（宣讲会/管理层常见）。
- 字体/格式：用最常见字体、PDF 交付，避免排版错乱。

## 八、常见误区（要主动纠正用户）

- ❌ 直接写"踏实肯干 / 勤奋好学"这类空话 → 用**具体经历侧面体现**。
- ❌ 编数据、编奖项、编角色 → 面试会露馅，且越过了红线。
- ❌ 无关内容塞满简历 → 稀释重点。
- ❌ 一版投所有岗位 → 匹配度低。
- ❌ 把没做过的事用"话术"包起来 → 这是造假，不是包装。
